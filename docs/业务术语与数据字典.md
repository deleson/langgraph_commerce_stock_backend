# 业务术语与数据字典

本文解释后端 API 中常见字段、枚举和状态值，方便前端展示和表单校验。

## 一、通用字段

| 字段 | 含义 | 示例 |
| ---- | ---- | ---- |
| `id` | 数据库主键 | `1` |
| `user_id` | 用户 ID，用于资源归属和隔离 | `12` |
| `created_at` | 创建时间 | `2026-06-15T10:00:00` |
| `updated_at` | 更新时间 | `2026-06-15T10:30:00` |
| `limit` | 查询条数上限 | `20` |
| `offset` | 分页偏移 | `0` |
| `total` | 列表总数 | `128` |
| `items` | 列表数据 | `[]` |
| `warnings` | 风险提示或限制说明 | `["K 线数量不足"]` |
| `errors` | 错误说明 | `["数据为空"]` |
| `disclaimer` | 免责声明 | `本结果不构成投资建议` |

## 二、市场与行情字段

| 字段 | 含义 | 可选值 / 示例 |
| ---- | ---- | ------------- |
| `market` | 市场代码 | `US`、`CN`、`HK` |
| `symbol` | 股票代码 | `AAPL`、`600519`、`0700` |
| `name` | 股票名称 | `Apple Inc.` |
| `currency` | 货币 | `USD`、`CNY`、`HKD` |
| `exchange` | 交易所 | `NASDAQ`、`SSE` |
| `timeframe` | K 线周期 | `1d`、`1h`、`5m` |
| `adjust_type` | 复权类型 | `none`、`qfq`、`hfq` |
| `source` | 数据来源 | `mock`、`baostock`、`tushare` 等 |
| `latest_price` | 最新价 | `172.4` |
| `previous_close` | 前收盘价 | `170.2` |
| `open_price` | 开盘价 | `171.0` |
| `high_price` | 最高价 | `173.5` |
| `low_price` | 最低价 | `169.8` |
| `close_price` | 收盘价 | `172.4` |
| `volume` | 成交量 | `83400000` |
| `amount` | 成交额 | `123456789.00` |
| `as_of` | 行情快照时间 | ISO datetime |

注意：`MarketDataSource` 的 Schema 中保留了 `akshare`、`alpha_vantage`、`polygon` 等值，但当前业务 Provider 主要实现 mock、baostock、tushare。前端不要仅凭枚举值判断某 Provider 已完整可用。

股票搜索和基础信息来源说明：

| 场景 | 当前行为 |
| ---- | -------- |
| 数据库已有股票基础信息 | `GET /market/stocks/search` 直接从 `market_symbols` 返回 |
| 数据库没有匹配结果 | 后端调用当前 `MARKET_DATA_PRIMARY_PROVIDER` 的 `search_symbols` |
| Tushare 搜索 | 当前通过 `stock_basic` 获取 A 股真实基础信息，包括 `symbol`、`name`、`exchange`、`curr_type` |
| 搜索结果缓存 | Provider 返回的基础信息会写入 `market_symbols`，后续搜索优先走数据库 |
| 前端处理 | 前端只需要展示统一返回的 `symbol`、`market`、`name`、`currency`、`exchange`，不需要直接调用 Provider |

`source` 表示数据来自哪个行情 Provider 或降级来源。它不是投资建议来源，也不代表数据一定完整可用；是否可用于技术指标、策略信号或回测，还要结合数据质量报告和 K 线数量判断。

## 三、AI 分析字段

| 字段 | 含义 |
| ---- | ---- |
| `thread_id` | 分析线程 ID，用于后续追问 |
| `analysis_type` | 分析类型，当前主要是 `stock_basic` |
| `graph_route` | 主分析图路线 |
| `quality_context` | 数据质量上下文 |
| `market_snapshot` | 行情快照 |
| `indicators` | 早期基础指标快照 |
| `technical_indicators` | 完整技术指标 |
| `strategy_signal` | 策略信号 |
| `result.summary` | AI 分析摘要 |
| `result.risk_level` | AI 给出的风险等级 |
| `result.trend` | AI 给出的趋势判断 |
| `result.key_points` | 关键观点列表 |
| `result.suggestion` | 研究建议文本 |
| `result.warnings` | 风险提示 |

`graph_route` 可选值：

| 值 | 含义 | 前端展示建议 |
| ---- | ---- | ------------ |
| `normal` | 数据正常，完整分析 | 正常展示 |
| `degraded` | 数据可用但存在风险 | 展示分析，同时突出数据风险 |
| `unavailable` | 数据不可用 | 展示不可用原因，不强调 AI 结论 |
| `error` | 图执行或数据处理错误 | 展示失败提示 |
| `quota_blocked` | AI 额度不足 | 提示额度不足或稍后重试 |

## 四、技术指标字段

| 字段 | 含义 |
| ---- | ---- |
| `ma5` / `ma10` / `ma20` / `ma60` | 简单移动均线 |
| `ema12` / `ema26` | 指数移动均线 |
| `rsi6` / `rsi12` / `rsi24` | 不同周期 RSI |
| `dif` / `dea` / `histogram` | MACD 三个核心值 |
| `daily_return_std` | 日收益率标准差 |
| `annualized_volatility` | 年化波动率 |
| `momentum_5` / `momentum_10` / `momentum_20` | 不同窗口价格动量 |
| `volume_ma5` / `volume_ma20` | 成交量均线 |
| `volume_ratio` | 最新成交量 / 20 期成交量均值 |

常见标签：

| 字段 | 可选值 | 含义 |
| ---- | ------ | ---- |
| `trend` | `bullish`、`bearish`、`neutral` | 趋势偏多、偏空、中性 |
| `rsi.status` | `oversold`、`neutral`、`overbought` | 超卖、中性、超买 |
| `macd.signal` | `bullish`、`bearish`、`neutral` | MACD 动能方向 |
| `volatility.level` | `low`、`medium`、`high` | 波动率风险等级 |
| `volume_factor.status` | `shrinking`、`normal`、`expanding` | 缩量、正常、放量 |

## 五、策略信号字段

| 字段 | 含义 |
| ---- | ---- |
| `status` | 策略信号是否可用 |
| `signal` | 策略动作 |
| `strength` | 信号强弱 |
| `score` | 0 到 100 的规则分 |
| `summary` | 策略信号摘要 |
| `reasons` | 支持理由 |
| `risks` | 风险提示 |
| `rule_results` | 各规则维度评分明细 |

`signal` 可选值：

| 值 | 含义 |
| ---- | ---- |
| `buy` | 规则分偏高，研究上偏买入信号 |
| `sell` | 规则分偏低，研究上偏卖出信号 |
| `hold` | 分数接近中性，倾向持有或等待 |
| `observe` | 数据或信号不够强，建议观察 |

注意：`buy` / `sell` 不是投资建议，也不是交易指令。

## 六、回测字段

| 字段 | 含义 |
| ---- | ---- |
| `initial_cash` | 初始资金 |
| `final_equity` | 期末权益 |
| `total_return` | 总收益率 |
| `annualized_return` | 年化收益率 |
| `max_drawdown` | 最大回撤 |
| `sharpe_ratio` | 夏普比率 |
| `win_rate` | 胜率 |
| `trade_count` | 交易次数 |
| `buy_count` / `sell_count` | 买入 / 卖出次数 |
| `total_commission` | 总手续费 |
| `total_slippage_cost` | 总滑点成本 |
| `daily_equity` | 每日权益曲线 |
| `trades` | 模拟成交列表 |
| `signal_snapshots` | 每日信号快照 |

回测决策值：

| 值 | 含义 |
| ---- | ---- |
| `buy` | 买入 |
| `sell` | 卖出 |
| `hold` | 持有 |
| `observe` | 观察 |
| `skip` | 样本不足或条件不满足，跳过 |
| `stop_loss` | 止损触发 |
| `take_profit` | 止盈触发 |
| `cooldown` | 冷却期拦截 |
| `drawdown_guard` | 最大回撤保护拦截 |

## 七、候选评分字段

| 字段 | 含义 |
| ---- | ---- |
| `universe_source` | 候选股票池来源，`manual` 或 `watchlist` |
| `top_n` | 返回前 N 个候选 |
| `decision` | `candidate` 或 `excluded` |
| `rank` | 排名 |
| `score` | 最终分数 |
| `grade` | A / B / C / D 评级 |
| `score_breakdown` | 分数拆解 |
| `excluded_reason` | 被排除原因 |

候选评分只表示研究优先级，不是荐股。

## 八、纸面交易字段

| 字段 | 含义 |
| ---- | ---- |
| `account_id` | 纸面交易账户 ID |
| `cash_balance` | 虚拟现金余额 |
| `initial_cash` | 初始虚拟资金 |
| `status` | 账户、订单或运行记录状态 |
| `position_market_value` | 模拟持仓市值 |
| `total_equity` | 虚拟总权益 |
| `unrealized_pnl` | 未实现盈亏 |
| `unrealized_return` | 未实现收益率 |
| `run_id` | 一次 tick 的运行记录 ID |
| `tick_status` | tick 执行状态 |

纸面交易账户状态：

| 值 | 含义 |
| ---- | ---- |
| `active` | 启用 |
| `paused` | 暂停 |
| `closed` | 关闭 |

订单状态：

| 值 | 含义 |
| ---- | ---- |
| `pending` | 待处理 |
| `filled` | 已模拟成交 |
| `cancelled` | 已取消 |
| `rejected` | 已拒绝 |
| `skipped` | 已跳过 |

tick 来源：

| 值 | 含义 |
| ---- | ---- |
| `manual` | 手动 |
| `api` | API 触发 |
| `background_task` | 后台任务触发 |
| `scheduler` | 定时任务触发 |
