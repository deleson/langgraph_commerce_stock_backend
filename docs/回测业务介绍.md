## 一、回测边界

回测只基于历史 K 线和确定性规则模拟：

```text
不连接券商；
不真实下单；
不构成投资建议；
不代表未来收益；
历史表现不能外推为未来收益承诺。
```

## 二、单股回测总体流程

```mermaid
flowchart TD
    A["BacktestRequest<br/>symbol / market / date range / risk_control"] --> B["读取历史 K 线"]
    B --> C{"数据是否满足要求"}
    C -->|否| D["返回 unavailable"]
    C -->|是| E["逐日生成策略信号快照"]
    E --> F["根据下一根 K 线开盘价撮合交易"]
    F --> G["应用手续费 / 滑点 / 止损 / 止盈 / 冷却期 / 回撤保护"]
    G --> H["生成每日权益曲线"]
    H --> I["计算绩效指标"]
    I --> J["BacktestResponse"]
```

## 五、信号生成和未来函数规避

单股回测逐日遍历 K 线：

```text
第 N 天信号只使用第 1 天到第 N 天的历史 K 线；
如果历史窗口少于 MIN_SIGNAL_WINDOW = 35，则跳过；
第 N 天收盘后生成信号；
交易在第 N+1 天开盘价模拟成交。
```

这样做是为了避免“偷看未来”。

```mermaid
sequenceDiagram
    participant D1 as 第 N 天及以前 K 线
    participant Signal as 策略信号
    participant D2 as 第 N+1 天开盘价
    participant Trade as 模拟成交

    D1->>Signal: 只使用历史窗口计算指标和信号
    Signal->>D2: 信号延迟到下一根 K 线执行
    D2->>Trade: 用下一日开盘价模拟成交
```

## 六、交易撮合

买入逻辑：

```text
1. 当前为空仓；
2. 决策为 buy；
3. 使用下一根 K 线开盘价；
4. 如果启用滑点，买入价 = open_price * (1 + slippage_rate)；
5. 按 position_size_ratio 计算可买整数股；
6. 扣除成交金额和手续费；
7. 更新现金和持仓。
```

卖出逻辑：

```text
1. 当前有持仓；
2. 决策为 sell / stop_loss / take_profit；
3. 使用下一根 K 线开盘价；
4. 如果启用滑点，卖出价 = open_price * (1 - slippage_rate)；
5. 卖出全部持仓；
6. 扣除手续费；
7. 计算 realized_pnl 和 realized_return。
```

手续费：

```text
commission = max(trade_value * commission_rate, min_commission)
```

滑点：

```text
买入成交价 = 原始开盘价 * (1 + slippage_rate)
卖出成交价 = 原始开盘价 * (1 - slippage_rate)
```

## 七、风控执行顺序

每个交易日会按顺序应用：

```text
止损
止盈
最大回撤保护
冷却期
买卖撮合
```

说明：

| 风控 | 行为 |
| ---- | ---- |
| 止损 | 当前收盘价跌破买入价按比例计算的触发价时，改写为 `stop_loss` |
| 止盈 | 当前收盘价高于买入价按比例计算的触发价时，改写为 `take_profit` |
| 最大回撤保护 | 空仓准备买入且账户回撤超过阈值时，跳过买入 |
| 冷却期 | 卖出后若仍处于冷却期，拦截新的 buy 信号 |

## 八、每日权益

每日权益计算：

```text
position_market_value = position_quantity * close_price
total_equity = cash + position_market_value
daily_return = total_equity_today / total_equity_yesterday - 1
drawdown = (peak_equity - total_equity) / peak_equity
```

前端可以用 `daily_equity` 画资金曲线、回撤曲线和持仓变化。

## 十、组合回测

组合回测用于模拟多只资产按目标权重构建组合并定期调仓。

```mermaid
flowchart TD
    A["PortfolioBacktestRequest<br/>assets / weights / rebalance"] --> B["读取多资产 K 线"]
    B --> C["取共同交易日"]
    C --> D["初始建仓"]
    D --> E{"是否到调仓日"}
    E -->|是| F["按目标权重调仓"]
    E -->|否| G["持仓估值"]
    F --> G
    G --> H["生成组合每日权益"]
    H --> I["计算组合绩效"]
    I --> J["PortfolioBacktestResponse"]
```

组合回测请求重点：

| 字段 | 说明 |
| ---- | ---- |
| `assets` | 2 到 20 个资产 |
| `target_weight` | 每个资产目标权重，总和必须为 1 |
| `cash_deploy_ratio` | 投入资金比例 |
| `rebalance_frequency` | 调仓频率 |
| `rebalance_interval_days` | 自定义间隔调仓天数 |

调仓频率：

```text
none
daily
weekly
monthly
interval
```
